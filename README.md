Coalmine AI Governance — SIH26024

This is the complete final source package for the current Coalmine AI Governance prototype. It is a static, responsive HTML/CSS/JavaScript application for demonstrating coal-mine compliance monitoring, risk analysis, violations, corrective actions, inspections, analytics, notifications, and reports.


Runtime scope


Frontend: artifacts/coalmine-governance/index.html

Application logic and SPA navigation: artifacts/coalmine-governance/app.js

Existing visual design: artifacts/coalmine-governance/style.css

Public assets: artifacts/coalmine-governance/public/

No backend server, database, API integration, API key, or real authentication system is used by this prototype.

All records and AI risk scores are fictional demonstration data.


Requirements


Node.js 24 or compatible modern Node.js runtime

pnpm


Install

From the package root:


pnpm install --frozen-lockfile

Run in development

The Vite configuration requires PORT and BASE_PATH:


PORT=23289 BASE_PATH=/ pnpm --filter @workspace/coalmine-governance run dev

Open http://localhost:23289/.


Build and preview the production bundle

PORT=23289 BASE_PATH=/ pnpm --filter @workspace/coalmine-governance run build
PORT=23289 BASE_PATH=/ pnpm --filter @workspace/coalmine-governance run serve

The production files are written to artifacts/coalmine-governance/dist/public/. The dist/ directory is intentionally excluded from this source archive because it is generated by the build.


Demo access

Use Enter demo mode on the login screen to explore the prototype. The prefilled demo-only login remains part of the source because it is required by the current prototype behavior; it is not a real account or production credential.


Final navigation behavior

The completed frontend includes:



SPA-style hash/history routing for all dashboard sections

Dashboard KPI and panel navigation

Mine rows and mine-detail modal flows

Violation, corrective-action, inspection, map, analytics, and report interactions

Notifications, search, logo/home navigation, logout, mobile sidebar navigation

Browser Back support and demo-session persistence across refresh


Project files

The source archive excludes node_modules, generated dist output, caches, build metadata, and secrets. There is no backend directory because this application does not use a backend.
