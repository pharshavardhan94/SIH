# Coalmine AI Governance — SIH26024

A dependency-free, responsive frontend prototype for the Smart India Hackathon problem statement:

> Build an intelligent software platform that helps coal-mine authorities monitor compliance, identify violations/risks, track corrective actions and generate useful governance insights.

## Run

Open `index.html` directly, or serve the folder with any static server. No build step, backend, database, API key, or package installation is required.

Use **Enter demo mode** on the login screen to explore the full command center.

## Prototype scope

- Responsive dark navy industrial-government command center
- Dashboard KPIs, charts, risk distribution, high-risk mine table and simulated AI risk engine
- Mine register with search and region/risk filters
- Mine details modal with compliance categories and inspection history
- Violation management with severity/status filters
- Corrective-action workflow with live status/progress changes
- Inspection management, geospatial risk map, governance analytics and reports
- Notifications, global search, toasts, modal flows and mobile sidebar

All names, records and statistics are fictional demonstration data. The AI Risk Engine is explicitly simulated for presentation purposes.
